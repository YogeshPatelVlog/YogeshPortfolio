# Yogesh Patel — Portfolio Website

A personal portfolio website showcasing my projects, skills, and internship experience — built with a clean, terminal-inspired UI theme.

🔗 **Live Site:**  - https://yogeshpatelportfolio.netlify.app/

## 📌 About

This portfolio highlights my journey as a BTech Computer Science student, covering my Android app development, full-stack Java projects, and internship experience at ApexPlanet Software and CodSoft.

## 🚀 Features

- Terminal-inspired, developer-focused UI theme
- Responsive design across devices
- Interactive project cards with GitHub & live demo links
- Timeline-based experience/internship section
- Smooth animations and transitions

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📂 Featured Projects

- **[Online Document Converter](https://github.com/YogeshPatelVlog/docuconverter)** — Full-stack document conversion platform (Java, Spring Boot, Apache PDFBox/POI)

## 💼 Experience

## 📦 Getting Started

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/YogeshPatelVlog/portfolio.git
cd portfolio
```

No build steps required — it's a static site.
